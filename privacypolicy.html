Privacy Policy

Last updated: September 30, 2026

Overview

Personal Google Drive Mount is a personal application used to access Google Drive from a Linux computer using rclone.

Google User Data

The application accesses Google Drive data only as necessary to perform file operations requested by the user through rclone.

Depending on the permissions granted to the application, these operations may include listing, reading, creating, modifying, and deleting files and folders in Google Drive.

Use of Data

Google user data is used solely to provide Google Drive access through rclone. It is not used for advertising, analytics, profiling, or any unrelated purpose.

Data Sharing

Google user data is not sold, rented, or shared with third parties.

Data Storage

The application does not operate an external server or database that stores Google Drive file contents. Authentication credentials required by rclone are stored locally on the user's computer.

Data Security

Access credentials and application configuration are maintained locally on the user's computer. The application does not provide these credentials to third parties.

Revoking Access

Access can be revoked at any time through the user's Google Account security settings.

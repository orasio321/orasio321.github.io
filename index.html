Personal Google Drive Mount

This application is a personal utility used to access and mount Google Drive on a Linux computer using rclone.

Purpose

The application uses Google's OAuth authentication to allow rclone to access my Google Drive account. This enables Google Drive files to be accessed through the local Linux filesystem.

Access to Google Drive

Google Drive access is used only for normal file operations requested by the user, such as listing, reading, creating, modifying, and deleting files.

This application is intended for personal use and is not offered as a service to other users.
